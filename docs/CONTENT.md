# Content checklist

The first version uses sample images and explicit placeholder text. Replace content in `src/content.ts`; replace each image at the path listed there. Preserve the `id` values (`01`, `02`, `03`) so existing links remain valid, or update the links at the same time.

## Introduction note

- Preferred name and the short introduction shown on the desk.
- A biography for the open note: what you do, what interests you, and what you want visitors to remember.
- Optional contact link to add later if you want people to reach you from the note.

## Polaroids

For each of the three photos, provide the image, a short caption, descriptive alt text, and one or two sentences for the detail view. Use web-optimized images with consistent square crops. Only publish photos you are comfortable sharing publicly.

## Travel postcard

Add visited countries to the `countries` array with their names. A short story for each country is optional. The decorative stamps do not claim to represent specific countries until you supply this list.
